# Brand logos

Drop an image in here and it appears on the brand picker and on every
project page for that brand. Nothing else to change -- the app picks up
whatever is in this folder at build time.

The name only has to mention the brand: `doghaus.png`, `Dog Haus.png` and
`Dog-Haus-logo-2024.png` all work, as do the brand's other names, so a file
straight out of a press kit usually lands correctly without renaming.
Spaces, capitals, apostrophes and extra words are all ignored. The tidy
names below are the ones to prefer.

| File name              | Brand              |
| ---------------------- | ------------------ |
| `jerseymikes.*`        | Jersey Mike's      |
| `daves.*`              | Dave's Hot Chicken |
| `mogu.*`               | Mogu               |
| `doghaus.*`            | Dog Haus           |
| `jmacquisitions.*`     | optional -- falls back to the Jersey Mike's logo |

`.svg`, `.png`, `.jpg` and `.webp` all work. SVG is best; otherwise a PNG
around 256px or larger. A transparent background is fine: logos sit on a
white plate so a dark wordmark stays readable in dark mode.

Any brand without a file here keeps its coloured initials, so a missing
logo looks deliberate rather than broken.
